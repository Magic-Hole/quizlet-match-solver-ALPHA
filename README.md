# Guigui++ Ultimate (Quizlet Match Solver)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

Une extension Chrome au design ultra-stealth et indétectable pour pulvériser le jeu **Associer (Match)** sur Quizlet.

Créé par **Guigui** ❤️ (Discord : `magic.term.`)

## 🌟 Fonctionnalités & Modes

*   **Scanner Universel Infaillible** : Récupère instantanément toutes les paires depuis le code source.
*   **Menu Flottant Stealth (Guigui++)** : Un widget caché en bas à gauche de la page Quizlet avec un menu déroulant.
*   **Mode 🟢 Surligneur** : Illumination totale de la case et de sa réponse au survol.
*   **Mode ⚡ Auto-Resolve** : Le bot résout tout seul le plateau. Vous choisissez le *Temps Total* (ex: 2.0s) et le script s'adapte !
*   **Protection Anti-Ban** : Simule les événements de clic natifs.

## 🚀 Installation

Puisqu'il s'agit d'une extension privée, voici comment l'installer :

1. Ouvrez Google Chrome et tapez `chrome://extensions/` dans la barre d'adresse.
2. En haut à droite, activez le **"Mode développeur"**.
3. Cliquez sur **"Charger l'extension non empaquetée"** (Load unpacked).
4. Sélectionnez le dossier contenant l'extension.
5. Épinglez l'icône de l'extension pour y accéder.

## ⚙️ Comment l'utiliser

1. Allez sur votre liste Quizlet.
2. Ouvrez l'extension et cliquez sur **Scanner Quizlet**.
3. Lancez le jeu **Associer**.
4. Cliquez sur le widget **Guigui++** en bas de page pour choisir votre mode (Surligneur ou Auto).
5. Jouez ou regardez la magie opérer !
